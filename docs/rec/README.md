# rec/ — video explicativo

Este directorio contiene el video asciinema de **Lectura de parámetros CashDro** y el reproductor
que se usa en la página del proyecto.

- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:03. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
